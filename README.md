# 耆安云盾 — 移动端应用

耆康云盾平台配套的移动端 H5 应用，面向长者家属和护理人员，提供实时体征查看、AI 健康解读、消息提醒与健康服务订购等功能。

## 功能模块

| 模块 | 说明 |
|------|------|
| **登录** | 账号密码登录，支持密码可见切换 |
| **首页** | 长者健康概览 — 心率、血氧、体温、步数等实时体征指标、7日趋势图、AI 健康解读 |
| **消息中心** | 健康预警、系统通知、服务提醒，未读角标实时更新，一键消警 |
| **健康服务** | 在线预约护士理疗、送医上门等服务，支持搜索与分类筛选 |
| **我的** | 长者档案管理、SOS 紧急联系人拨号、设备物联状态查看 |

AI 健康解读基于大语言模型 API（支持 DeepSeek、通义千问、智谱 GLM 等国产大模型），对长者当日体征数据生成个性化分析报告；未配置 API Key 时自动降级为本地备用分析。

## 技术栈

- **前端**：React 19 + TypeScript + Tailwind CSS 4 + Motion
- **构建**：Vite 6 + esbuild
- **服务端**：Express（SSR + API 代理）
- **AI**：DeepSeek / 通义千问 / 智谱 GLM 等国产大模型 API
- **图标**：Lucide React

## 本地运行

**前置条件**：Node.js >= 18

```bash
# 1. 安装依赖
npm install

# 2. 配置环境变量（可选，不配置则 AI 解读走本地备用逻辑）
cp .env.example .env.local
# 编辑 .env.local，填入 GEMINI_API_KEY

# 3. 启动开发服务器
npm run dev
```

应用默认运行在 `http://localhost:3000`。

测试账号：`user1` / `123456`

## 构建与部署

```bash
npm run build    # 输出到 dist/
npm run start    # 运行生产构建
```
